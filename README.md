# 🏋️‍♂️ FitUp Pro v15.7 Accelerated

> **A 80-Week (560-Day) Prescriptive FitUp v15.7 Accelerated Training & AI Nutrition System featuring "Zero Decisions" 3-Button Set Outcome Tracking, Performance-Based Unlocks, Gradual Myo-Reps Arm Block Clusters (from Week 3), Biceps 4-Week Microcycle (3:1), Auto-Regulated Deloads, Dual-Cadence Progression Engine, Cervical Health Protocol, Adaptive Intra-Workout Rest Timers, Dynamic Muscle Anatomy Tracking, and Google Fit & Drive Sync.**

## 🌟 Overview

**FitUp Pro v15.7 Accelerated** is an advanced, offline-first Web Application designed for long-term physical progression, hypertrophic gains, cardiovascular conditioning, and precision workout tracking.

Built on a strict **"Zero Decisions" Philosophy**, every single workout day across the 80-week (560-day) period is fully prescribed—down to exact exercise ordering, target rep ranges, weight progressions, legal dumbbell increments, tempo control, rest intervals, structural tags, and micro-mobility integration.

Set completion operates under an objective **3-Button Outcome Classifier** (🚀 **ABOVE**, ✅ **IN_WINDOW**, ⚠️ **BELOW** / Mechanical Stop), which feeds the atomic progression engine and adjusts intra-workout rest timers dynamically (+30s extension on mechanical stop).

## ✨ Key Features

### 🏋️‍♂️ Prescriptive 80-Week Accelerated Training Engine
- **v15.7 Accelerated Architecture**: Protected heavy compounds in straight sets, non-competing & antagonist Lean Pairs, Core Circuit, Calf Block, and Weekly Toggles.
- **Phase 0 Anatomical Foundation (Weeks 1–4) & Performance-Based Graduation**: Reduced initial volume (5–6 anchor exercises per session, 20m light walks) protecting connective tissue and lumbar spine. From Week 3, locked movements unlock as soon as performance criteria are met (Calendar Ceiling Rule — performance can only accelerate, never delay). VO2 Max 4x4 launches in Week 4, followed by the automatic Week 5 Graduation Event unlocking remaining full volume (BSS, OHP/Pike, Towel Hang, and L-Sits).
- **Zero Decisions 3-Button Outcome Selector & Minimum Weight Protection Engine**: Objective set classification with physical floor protection (6 kg empty handle / 8 kg loaded for dumbbells; 5 kg for vest) preventing invalid 0 kg displays under any fallback.
- **Objective Myo-Reps & Arm Block Protocol**: Micro-dosing begins progressively from **Week 3 onwards** (W3: 1+1×4, W4–5: 1+2×4, W6+: 1+3×5 full cluster). Objective stop rule (`two_consecutive_tempo_losses`) with a weekly exposure limit of 1 per muscle area (Lateral Shoulder, Triceps, Biceps).
- **Biceps 4-Week Microcycle (3:1)**: 3 heavy progressive overload weeks + 1 light preservation week (Single-Arm Hammer Curl 2 sets, no progression) to maximize hypertrophy while protecting elbow joints.
- **Dual-Cadence & Softened Progression Engine**: `🚀 ABOVE` triggers immediate early promotion; in-window / softened performances accumulate towards the Dual-Cadence ladder (+2 kg every 3rd workout for Group A compounds, every 4th workout for Group B isolations) to protect joint tendons, while bodyweight stages advance directly upon achieving softened criteria.
- **Deload Every 12 Weeks + Auto-Regulated Deload**: Calendar deloads on Weeks 12/24/36/48/60/72, plus an automatic early deload triggered by 2 consecutive failed sessions, excessive load demotions, or repeated joint-pain flags — with an explanatory banner.
- **Weekly Frequency Additions**: 2nd Back Frequency (TRX Row on Day 3 = 10 weekly back sets) and 2nd Chest Frequency (Push-Up Volume on Day 5 = 8 weekly chest sets).
- **Cervical Health Protocol**: Dedicated Band Neck Flexion & Extension protocol on Day 4 for neck/postural resilience.
- **Adaptive Intra-Workout Rest Engine**: Dynamically calculates rest timers with automatic +30s extensions following a mechanical stop (`BELOW` outcome).
- **Cardiovascular & Recovery Integration**:
  - **Norwegian 4x4 VO2 Max**: High-intensity interval treadmill running capped at ≤6% incline for joint protection.
  - **Zone 2 Cardio & Micro-Mobility**: Dedicated active recovery days and dead hangs/thoracic extensions integrated into rest periods.

### 🧬 Dual-Mode Anatomy Visualizer & Biomechanical Joint Engine
- Dual-mode switch: **🦾 Muscles & Load (14 Muscle Groups)** ⟷ **🛡️ Joints & Vulnerabilities (12 Critical Joint Nodes)**.

## 📋 Training Program Deep Dive

The **FitUp Pro v15.7 Accelerated** program is engineered specifically for home-gym training with high-volume, high-efficiency hypertrophy and cardiovascular optimization over 80 weeks (560 days).

### 🗓️ Weekly Microcycle Architecture (7 Days)
Each week follows a strictly optimized 7-day routine designed to balance muscular stimulus, joint recovery, and metabolic conditioning:

| Day | Workout Type | Focus / Key Movements | Target Duration |
| :--- | :--- | :--- | :--- |
| **Day 1 (Mon)** | **Legs + Core + Carry** | Goblet RDL (W1–17) / Contralateral Hand-Supported Single-Leg RDL (W18+), Nordic Curl Progression (W10+), Heels-Elevated Goblet Squat, Goblet BSS, DB Glute Bridge, Suitcase Carry, Core Circuit | 60–65 min |
| **Day 2 (Tue)** | **Zone 2 Cardio** | Treadmill Walking (60–70% HRmax / Zone 2 target, 4% incline @ 5.5 km/h base), Daily Micro-Mobility | 45 min |
| **Day 3 (Wed)** | **Push + Shoulders + Skill + Calves** | Single-Arm Seated OHP (A1) → Overhead Skill Tree (A2) → Single-Arm Floor Press (A3) → **Chin-Up (A4, 2×4–8, antagonistic vertical pull)** → Push-Up Tree (A5) → DB Overhead Triceps Ext (A6) → TRX Row ↔ Single-Arm Lateral Raise pair (A7/A8) → Rear Delt Toggle (A9) → **Calf Block (A10/A11 — moved from Day 5 to spare Achilles)** → Arm Block (W3+ Gradual Ramp) | 60–65 min |
| **Day 4 (Thu)** | **Active Recovery & Joint Health** | Band Neck Flexion & Extension protocol (A1), Light Treadmill Recovery Walk (A2), 10-min Deep Mobility sequence (A3) | 30 min |
| **Day 5 (Fri)** | **Pull + Grip + Core + Chest Vol** | Pull-Up Progression (A1), One-Arm DB Row (A2), TRX Face Pull ↔ Single-Arm Lateral Raise pair, Push-Up Volume ↔ Single-Arm Curl pair, Single-Arm Hammer Curl, Towel Hang ↔ L-Sit pair, Arm Block (W3+ Gradual Ramp) | 55–60 min |
| **Day 6 (Sat)** | **Cardio VO2 Max** | Norwegian 4x4 Interval Protocol (4×4 min @ 85–95% HRmax target; Walking: 5.8–6.8 km/h @ 4–6% incline | Running: ≥7.5 km/h @ 1–2% incline to spare Achilles tendon; 3 min recovery @ 60–70% HRmax) | 35 min |
| **Day 7 (Sun)** | **Complete Rest** | System Regeneration, Hydration & Passive Recovery | — |

### ⏱️ v15.9 Accelerated Architecture & Structural Optimization
The program organizes exercises into optimized structures to maximize metabolic density while protecting compound lifts (realistic target session duration: **60–65 minutes** on strength days):
1. **Protected Compound Lifts & Antagonistic Sequencing**: Heavy compounds are protected as straight sets. Day 3 inserts the Chin-Up at position #4 (between Floor Press and Push-Up Tree) to give anterior shoulder/triceps pressing muscles a complete neuromuscular break while driving vertical pulling frequency (2×/week).
2. **Ping-Pong Resolution & Transition Buffer**: Single-Arm Lateral Raise working rep window is optimized to **10–18 reps** with strict 2-1-2 tempo. Stepping from 6 kg to 8 kg incorporates a 2-session Transition Rep Buffer (8–18 reps at 8 kg maintains load) eliminating premature demotion loops.
3. **Unilateral Alternating Sets**: Unilateral exercises are performed alternating sides per set (Right set 1 → Left set 1 → 60–75s rest → Right set 2 → Left set 2) to eliminate session bloat and maintain cardiovascular density.
4. **Volume Stepping vs. Arm Block Collision Rule**: When a main exercise enters Volume Stepping (`prescribedSets > baseSets`), the corresponding Arm Block for that muscle area is automatically suppressed to protect tendons and prevent 11–12 weekly sets on small muscle groups.
5. **Achilles Tendon Guard**: Calf Block is scheduled on Day 3 (Wednesday), providing >60 hours of connective-tissue recovery before Day 6 Norwegian 4×4. Running intervals (≥7.5 km/h) are capped at 1–2% incline to prevent eccentric Achilles recoil overload.
6. **L4–S1 Disc Protection**: Single-Leg RDL mandates Contralateral Hand Support (non-working hand lightly touching a wall/chair) to eliminate rotational spinal shear. Hollow Body Hold and L-Sit enforce strict posterior pelvic tilt and knee tuck cues.
7. **Multi-Joint Clinical Safety Engine**: Secondary substitutes provided for upper-body movements (`Band Pull-Apart`, `Scapular Push-up`), strict ban on consolidating extra sets onto injured joints, and conflict resolution across multi-joint injuries.
8. **Nutrition & Combat Training Boost**: On combat days (Muay Thai / MMA), targets receive a **Combat Refuel Boost of +450 kcal and +60g carbohydrates**. Maintenance/Recomp phase provides 2,650 strength / 2,450 recovery / 2,250 rest kcal.

## 🚀 Quick Start & Usage

### 1. Running Locally
Because FitUp Pro Ultimate is built on vanilla web standards, you can serve it with any HTTP static file server:

```bash
# Using Python builtin HTTP server
python3 -m http.server 8080

# Or using Node.js npx serve
npx serve .
```

Open your browser and navigate to `http://localhost:8080`.

### 2. Regenerating Program Data
If you modify the training schedule or volume logic in `generate_program.py`, compile the dataset and sync Git:

```bash
make gp
```

*This command executes `python3 generate_program.py`, updates `js/data.js` and `training_data.json`, commits the changes, and pushes to the `main` branch.*
