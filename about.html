Application Purpose

What is FitUp?

FitUp is a non-commercial, private personal fitness tracking web application designed to help individuals follow structured 78-week prescriptive workout routines, log exercise volume, monitor daily caloric balances, and measure strength progression over time.

Core Features of FitUp

  • 78-Week Prescriptive Training Plan: Guided progressive overload program with target sets, reps, and tempo guidance.
  • Interactive Muscle Progression Map: Visual anatomical breakdown of trained muscle groups and volume distribution.
  • AI Nutrition Analysis: Automated meal logging and calorie tracking powered by Google Gemini AI.
  • Strength Analytics & 1RM Prediction: Estimated One Rep Max tracking using the Epley formula.
  • Google Fit Integration: Daily step count, active calorie sync, and heart rate monitoring.
  • Google Drive Cloud Backup: Private JSON data synchronization across all user devices.

Google OAuth & Data Use Policy

FitUp integrates with Google Services strictly to enhance user personal fitness tracking while protecting user privacy:

☁️ Google Drive API Scope (drive.file)

FitUp uses the https://www.googleapis.com/auth/drive.file scope solely to create and update a single private backup JSON file (fitup-data.json) in the user's personal Google Drive. FitUp has no access to any other files in the user's Drive.

⌚ Google Fit API Scopes (fitness.activity.read & fitness.body.read)

FitUp accesses Google Fit to read daily step counts, expended activity calories, and heart rate metrics. This data is displayed in the user's personal daily nutrition and fitness dashboard to adjust energy balance estimates. No user health data is sold or shared with any third party.
