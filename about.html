Application Overview

What is FitUp?

FitUp Pro v15.6 Lean Edition is a non-commercial, private personal fitness tracking web application designed to help individuals follow structured 80-week (560-day) prescriptive workout routines under a zero-decision protocol (with 3-button set outcome reporting: Above Target 🚀, In Window ✅, Mechanical Stop ⚠️), log exercise volume, monitor daily caloric & protein balances, analyze meals with AI, and track long-term body composition transformation over time.

Core Features & Systems

  • 80-Week Prescriptive Lean Training Engine: Guided progressive overload program featuring 15 periodized phases, Zero Decisions set outcome tracking, Myo-reps clusters, and Arm Block ladders.
  • Zero Decisions 3-Button Set Tracker: Objective set outcome logging (🚀 Above Target, ✅ In-Window, ⚠️ Mechanical Stop) with dynamic adaptive rest extensions (+30s on failure).
  • Google Fit Health Integration: Real-time synchronization of daily step counts, active activity calories burned, and heart rate exertion metrics.
  • Interactive 14-Muscle Anatomy Map: Sci-Fi character model tracking real-time muscle volume distribution and stimulus across 14 target muscle groups.
  • Gemini AI Nutrition Coach: Automated meal photo recognition, calorie/macro estimations, sodium warnings, and personalized diet feedback using Google Gemini AI.
  • RPG Skill Tree & Level Progression: Gamified level progression (500 XP per strength day, 200 XP per walk day) with interactive skill tree nodes unlocked week-by-week.
  • Progress Photo Tracker & Consistency Map: On-device compressed progress photo journal and a 364-day visual consistency matrix.
  • Google Drive Cloud Backup: Private JSON data synchronization (drive.file scope) with client-side AES-256 key encryption across all user devices.

Exercise Library

Google OAuth & Data Use Policy

FitUp integrates with Google Services strictly to enhance user personal fitness tracking while protecting user privacy:

☁️ Google Drive API Scope (drive.file)

FitUp uses the https://www.googleapis.com/auth/drive.file scope solely to create and update a single private backup JSON file (fitup-data.json) in the user's personal Google Drive. FitUp has no access to any other files in the user's Drive.

⌚ Google Fit API Scopes (fitness.activity.read & fitness.body.read)

FitUp accesses Google Fit to read daily step counts, expended activity calories, and heart rate metrics. This data is displayed in the user's personal daily nutrition and fitness dashboard to adjust energy balance estimates. No user health data is sold or shared with any third party.
