# FitUp Pro — Prompt for AI: Hybrid v5.0 Upgrade

## Context
You have the **FitUp Pro v4.0** 52-week bodyweight program (Hebrew, RTL). It uses only:
- 3 resistance bands (30kg, 40kg, 50kg)
- Pull-up bar
- Chair/bench/table
- Towel
- Floor + wall

## What Needs to Change: Hybrid v5.0

### 1. Philosophy Shift
- **From:** Slow volume accumulation → endless reps of same exercises
- **To:** Minimum time, maximum results, zero injuries
- **Guiding principle:** Every 3-week block introduces a harder exercise variation. Never just "more reps."

### 2. Weekly Structure (Hybrid)

| Day | Type | Duration | RPE |
|-----|------|----------|-----|
| Sun | Lower Strength (Legs) | 35-40 min | 7-8 |
| Mon | Active Recovery — Brisk Walk | 30 min | — |
| Tue | Upper Push (Chest/Shoulders) | 35-40 min | 7-8 |
| Wed | Active Recovery — Relaxed Walk | 25 min | — |
| Thu | Upper Pull + Skill (Back/Arms + Skill Work) | 40-50 min | 7-8 |
| Fri | Active Recovery — Brisk Walk | 30 min | — |
| Sat | Rest | — | — |

### 3. Deload Schedule
- **Every 6 weeks** (not 4): Weeks 6, 12, 18, 24, 30, 36, 42, 48, 52
- Deload = same exercises, 50% volume (sets and reps halved, rounded down)
- Week 52 = final deload only

### 4. Warmup (Universal — every workout, 5 min)
1. High Knees ×20
2. Arm Circles ×10 each direction
3. Wall Slides ×10
4. Scapular Push-up ×10
5. Dead Bug ×6 each side

**No warmup for Active Recovery walks.**

### 5. Rest Between Sets

| Exercise Type | Rest |
|---------------|------|
| Pull-up / Chin-up / Negatives / L-sit variations | 2.5 min |
| Squat / Lunge / Split / Skater / Pike / Decline / Archer / Wall Walk | 2 min |
| Push-up / Row / Band Curl / Calf Raise / Glute Bridge | 90 sec |
| Scapular / Prehab (Y-T-W, Pull-Apart, Dead Bug, Side Plank) | 60 sec |
| Warmup / Recovery exercises | continuous, no rest |

**Tempo:** Smooth and controlled always. Negatives = continuous 3-5 second descent. No intentional pauses.

### 7. Skill Day (Thursday) — NEW COMPONENT

Thursday is NOT "Workout C." It is **Skill + Pull Strength**:

**Part A — Pull Strength (20 min):**
- Main pull exercise of current phase (Pull-up/Chin-up/L-sit Pull-up)
- Scapular Pull-up (warmup for pull)
- Band Curl (2-3 sets)
- Towel Grip Hang

**Part B — Skill Work (15-20 min):**
- Handstand practice (wall or freestanding attempts)
- L-sit practice (chair → floor)
- Mobility flow: Arm Circles, Wall Slides, Scapular Push-up (higher reps, no rest)

**Part C — Core Finisher (5-10 min):**
- Current phase core exercise
- Side Plank Hip Dip

### 8. Volume Rules (Sets × Reps)

- **Beginner phases (1-3):** 3-4 sets, 8-12 reps (or 15-30 sec for holds)
- **Intermediate phases (4-6):** 3-4 sets, 6-10 reps (harder variations = fewer reps)
- **Advanced phases (7-9):** 3-5 sets, 3-8 reps (strength focus)
- **Never** go below 3 reps except for holds (handstand, L-sit, towel hang)
- **Never** do more than 5 sets per exercise (time cap)
- **Never** do more than 6 exercises per workout (including warmup = 5 + warmup)

### 9. Key Constraints (DO NOT VIOLATE)

1. **Equipment:** ONLY bands (30/40/50kg), pull-up bar, chair/bench, towel, floor, wall
2. **Decisions:** ZERO user decisions. Every workout is prescribed. Only decision is "skip or do."
3. **Time:** No workout exceeds 50 minutes including warmup
4. **Injury prevention:** If a phase feels too hard, repeat the week. Deload is mandatory, not optional.
5. **No barbells, dumbbells, kettlebells, gym machines, rings, or parallettes.**
6. **No cardio machines.** Walking only for recovery.

### 13. Critical Rules for Week Construction

1. **Each 3-week block = one phase.** Do not change exercises mid-block.
2. **Week 3 of each block = peak volume** (most sets/reps before deload).
3. **Deload week = same exercises as Week 3, but 50% volume.**
4. **After deload, next block starts with NEW exercise variation.**
5. **If user fails to complete prescribed reps for 2 consecutive weeks, repeat that week (do not advance).**
6. **Thursday (Pull + Skill) always includes:** main pull exercise + scapular work + handstand practice + L-sit practice + core finisher.
